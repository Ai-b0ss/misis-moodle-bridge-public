# MISIS Moodle — hybrid-v7, 24.10.2026

## Новое в v7

**Постраничный OCR в PDF со смешанным содержимым.** Ранее при наличии нормального текстового слоя хотя бы на части PDF OCR сканированных страниц мог не запускаться. В модуле moodle_materials.py страницы с малым количеством извлечённого текста и встроенным растровым изображением выбираются для локального PP-OCRv5 (до 8 за один документ). Обычный текст сохраняется, OCR дописывается с исходным номером страницы. Для полностью нетекстового PDF оставлена резервная обработка первых трёх страниц.

Обновлено moodle_ocr.py: функция pdf_ocr допускает точечный список индексов страниц. Лимиты на количество страниц, пиксели, размер изображения и тайм-аут локального OCR сохраняются. OCR никогда не отправляет файлы во внешние сервисы.

Новый параметр команды:
python moodle_client.py index-materials --refresh-scans --limit 3 --budget-mb 30
Он повторно обрабатывает только PDF, включая ранее индексированные, с ограничением на количество документов и объём загрузок. Без --refresh-scans обычная инкрементальная логика остаётся прежней.

Реальная проверка: 3 PDF Moodle повторно прочитаны без ошибок. Синтетический PDF с первой текстовой страницей и второй сканированной страницей распознан полностью. Новые тесты test_mixed_ocr_v7.py (2/2). Полный набор 73/73 тестов успешен.

## Проверка остающихся ограничений

- Google Slides: из семи презентаций, ранее дававших TimeoutError, шесть публичных URL в Chromium возвращают HTTP 410 Gone (публикация недоступна), седьмая не прошла тест навигации браузера по иной причине. Остальные 7 частично читаемых презентаций по-прежнему требуют улучшения обработки; два повторных чтения не повысили охват. Итого 25/39 полностью прочитано, 584 слайдовые записи.
- Официальный mod_lesson_get_pages возвращает метаданные страницы, но не поле contents. Для 79 страниц Lesson по-прежнему требуется активная попытка. Метод mod_lesson_get_page_data проверяет таймер попытки; автоматического запуска попыток нет.
- Официальный Moodle mobile browser autologin требует отдельный приватный токен мобильного клиента. Защищённое локальное хранилище содержит только REST-токен и username, приватного токена нет. Поэтому отдельный Chrome-профиль остаётся неавторизованным. Не копировать cookies и не обходить SSO.
- Яндекс Диск: 26/27 документов текстово проиндексировано, один PDF по-прежнему отвечает HTTP 500 файлового сервера. 4 видеозаписи представлены лишь как метаданные, включая очень крупный файл; видео автоматически не загружать.
- 13 Assign скрыты правами Moodle: uservisible=false. Их содержимое не пытаемся открыть через сторонние парсеры.
- Глобальный серверный поиск выключен; локальный индекс охватывает только доступный и фактически обработанный материал.

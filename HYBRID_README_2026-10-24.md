# Moodle MISIS — гибридная система (24.10.2026)

Цель: читать максимально возможное содержимое собственного Moodle newlms.misis.ru, не обходя права студента и не изменяя учебные попытки/оценки.

## Реализованные компоненты

1. moodle_client.py — главный CLI и защищённый Moodle API; пароль из DPAPI-хранилища удалён, действует только зашифрованный токен.
2. moodle_extended.py — задания, статусы, оценки, тесты, календарь.
3. moodle_hybrid.py — локальный шифрованный DPAPI-индекс обычных страниц, метаданных уроков, словарей, H5P, меток и ссылок; обновление прав при каждом поиске.
4. moodle_materials.py — шифрованный индекс PDF, DOCX и PPTX. Для PDF без текстового слоя задействован OCR.
5. moodle_ocr.py, moodle_ocr_worker.py — локальный RapidOCR PP-OCRv5 cyrillic, изолированный в .ocrvenv. Документ передаётся только в памяти между локальными процессами.
6. moodle_lessons.py — чтение уже доступных страниц уроков. Новые попытки никогда не стартуют при обычном поиске.
7. moodle_browser.py — отдельный Chrome-профиль для страниц, которые доступны в UI, но не в мобильном API. Браузерный профиль пока НЕ авторизован.

## Ограничения

13 Assign имеют uservisible=false; это ограничения прав, не неисправность клиента.
core_search_get_search_areas_list возвращает globalsearchdisabled; заменён локальным индексом.
Бинарные старые PPT, H5P-интерактив, видео и слайды-картинки пока не имеют гарантированного полного текстового покрытия.
Browser GET может регистрировать просмотр; не использовать браузер для бессистемного сканирования оцениваемых активностей.
Любая попытка требует отдельного подтверждения. Автоматическая отправка работ не включена.
Домашний ПК должен быть доступен; внешний сервер с токеном не создавался.

## Этап 4 — максимальный охват лекций, 24.10.2026

Дополнительно к описанному выше:

- moodle_ppt_worker.py — чистый бинарный OLE-парсер PowerPoint 97–2003 для TextCharsAtom/TextBytesAtom, без запуска Office и макросов. Запускается из .ocrvenv через stdin/stdout. Добавлено 7 старых PPT в индекс, теперь PDF/DOCX/PPTX/PPT: 108/108 подходящих файлов без ошибок.
- moodle_slides.py — читает опубликованные или общедоступные Google Slides по /pubembed И /embed из обычного разрешённого просмотра Chrome. Извлекает текст посредством доступных DOM aria-label по каждому слайду. Не использует Google аккаунт, пароль, API-токен или screenshot/OCR; текстовый индекс DPAPI. Презентации, переставшие грузиться/перелистываться, помечает неполными/ошибкой. Есть прогрессивное пополнение и проверка права Moodle при поиске.
- moodle_drive.py — читает PDF по публично разрешённым Google Drive /file/d/ID/preview. Прямое скачивание для этих файлов возвращало HTML; поэтому используется нормальный браузерный просмотрщик и его реальный текст постранично. Ленивая подгрузка отрабатывается скроллом и дополнительным выборочным переходом к пропущенным страницам. В результате все 6/6 PDF, 362/362 страниц, имеют доступный текст и индексируются в локальный DPAPI.
- Единый hybrid-search объединяет страницы Moodle (386 записей), вложения Moodle (108 файлов), опубликованные Google Slides (по мере индексации) и PDF из Google Drive (6 файлов, 362 страницы). Система в момент выдачи поиска перепроверяет текущую видимость исходных модулей Moodle.

Новые команды через moodle_client.py:
- slides-index --limit 10 — пополнение опубликованных Google Slides, один слайд за другим;
- slides-status — статистика по завершённым и частично прочитанным презентациям;
- slides-search --query "тема" --limit 20 — поиск по номерам слайдов и текстам;
- drive-index --limit 2 — постраничная индексация легально просматриваемых PDF из Google Drive;
- drive-status — число файлов и страниц;
- drive-search --query "тема" — постраничный поиск;
- hybrid-search --query "тема" --limit 20 — объединённый результат из четырёх источников.

Ограничения НЕ отменены: учебные попытки, скрытые задания и запреты, заданные преподавателем, не обходятся; серверный поиск глобально отключён. Изолированный браузерный профиль Moodle требует собственную авторизацию для непубличных веб-страниц. Для Google Slides некоторые публикации нестабильны: полноту проверять по complete, не путать прочитанные слайдовые записи с числом полностью просмотренных презентаций.

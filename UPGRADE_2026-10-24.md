# Moodle MISIS API — modernized read-only facade (2026-10-24)

## What changed
- Added moodle_extended.py: a unified API layer for enrolled courses, course modules, Assign submissions, Quiz deadlines, calendar, grades and local search.
- Main CLI moodle_client.py routes overview, deadlines, search, grades, audit to the unified facade.
- Full report checks ALL available Assign submissions; the previous first-40 limit is removed.
- New setup hides the entered password and stores only the API token in Windows DPAPI. Existing credentials were NOT changed or migrated.
- Read-only API allowlist prohibits writing methods in the facade; transient network errors get one retry; permission errors never retry.
- No automatic launches, page-view tracking, file uploads, submission or grading. Do not bypass ACLs.

## Commands (run on Windows only)
Python: C:\Users\user\AppData\Local\Programs\Python\Python313\python.exe
Client: C:\Users\user\Documents\MISIS-Moodle-Bridge\moodle_client.py

  python moodle_client.py check
  python moodle_client.py overview --limit 10
  python moodle_client.py deadlines --limit 20 --tz-offset 3
  python moodle_client.py search --query "название лекции" --limit 10
  python moodle_client.py search --query "слово" --with-pages --limit 10
  python moodle_client.py grades
  python moodle_client.py audit --fast
  python moodle_client.py full

The actual Python executable/path should be specified if outside the project directory.
--fast skips submission-status verification. Without --fast, overview/deadlines checks every API-visible Assign submission (not a fixed first 40).
--with-pages reads accessible mod_page HTML only. It does not automatically open graded lessons, quizzes, Google Slides or restricted material.
The default deadline timezone is UTC+03:00 (Moscow), overridable via --tz-offset integer.
Reports may contain private education information: don't paste raw reports publicly.

## Semantics and limits
- The inventory of all course modules may be larger than the Assign API's allowed assignments. Never treat inaccessible assignments as completed or absent.
- The Moodle "No access rights in module context" warnings are permission restrictions, not evidence that the entire API failed.
- 464 advertised Moodle functions do NOT imply 464 authorized or integrated methods.
- Quiz close time is a deadline only for supported quizzes. Calendar events may be reminders rather than submission deadlines.
- State "submitted" is from mod_assign_get_submission_status, not a generic Moodle completion flag.
- Search indexes module names and sections by default; --with-pages also indexes accessible page HTML, not attachments or lesson slides.
- No autonomous access if the Windows PC is offline, no global Moodle search where the server has globalsearchdisabled.
- Legacy token file may still contain the historically saved password; it is deliberately untouched to avoid invalidating this session. Future setup is token-only.
- Password/token must never appear in logs, external URLs, Google Drive, or library skills. The token remains DPAPI encrypted on Windows.

## Этап 2 (24.10.2026) — защищённый полнотекстовый индекс

Рабочий модуль moodle_materials.py; использует только локальные DPAPI-credentials и скачивает через https://newlms.misis.ru/webservice/pluginfile.php/ без редиректов. Другим сайтам токен не передаётся. На диске сохраняется только шифрованный DPAPI-индекс .moodle_materials.dpapi; бинарники файлов не сохраняются.

Команды через moodle_client.py:
- index-materials --limit 15 --budget-mb 75 — постепенное индексирование новых или устаревших по сроку записей, максимум 32 МБ на файл и 400 МБ за запуск;
- materials-status — размер индекса и число обработанных файлов;
- find-materials --query "термин" --limit 20 — поиск по локальному индексу с актуальной перепроверкой разрешений;
- search --query "термин" --with-pages --with-files --limit 20 — единый поиск по модулям, HTML-страницам и индексированным текстам вложений.

Поддерживаются доступные PDF (с извлекаемым текстом), DOCX, PPTX. Обработано 101/101 доступных для индексирования объектов, ошибок 0 (24.10.2026).

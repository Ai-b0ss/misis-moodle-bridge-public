## Новые возможности — уже в главном CLI moodle_client.py

check / courses / tasks / full — прежние команды.
overview / deadlines / grades — общие учебные данные.
hybrid-index / hybrid-status — зашифрованный индекс страниц, ссылок, уроков.
hybrid-search --query "тема" --limit 20 — единый поиск по Moodle, вложениям, опубликованным слайдам Google и PDF Google Drive.
index-materials / materials-status / find-materials — PDF/DOCX/PPTX/PPT + локальное распознавание русских сканированных PDF.
slides-index / slides-status / slides-search — чтение Google Slides через DOM accessibility текста публичных /pubembed и /embed.
drive-index / drive-status / drive-search — чтение Google Drive PDF через доступный Preview, включая ленивую подгрузку и страницы.
lessons / lesson --cmid ID — чтение уроков без открытия новых попыток.
browser-status / browser-read / browser-login — резервный Chrome-профиль для Moodle HTML. Отдельный профиль НЕ авторизован. Авторизация самим пользователем с MISIS-Moodle-Web-Login.cmd.
start-practice --cmid X --confirm-cmid X — отдельно разрешённая команда, меняющая состояние Moodle; не вызывать без просьбы пользователя о конкретном тренировочном уроке.

## Остались ограничения

1. Права Moodle. 13 Assign имеют uservisible=false. Просмотр запрещён системой текущему студенту: обход чужих прав не предусмотрен. Если скрыто ошибочно — обсуждать с преподавателем/поддержкой.
2. Уроки. В 24 Lesson обнаружено 82 страницы, 3 уже читаются, 79 требуют активной попытки (cannotfindtimer), ещё один урок возвращает lessonnotready2. Нельзя автоматически запускать оцениваемые попытки ради индексирования.
3. Браузерная сессия. Изолированный Chrome запускается, но его проверка показывает authorized=false. Для защищённых HTML страниц требуется один вход в этом профиле; нельзя автоматически переносить cookies из основного Chrome.
4. Google Slides. 25 из 39 полностью, 7 частично, 7 не загрузились. Графика, диаграммы и заметки выступающего могут отсутствовать в текстовых aria-label. Нужна адресная проверка и, где допустимо, локальное OCR.
5. H5P/видео/внешние ссылки. H5P: 2 модуля с метаданными, но интерактивный контент не индексирован полностью. VKVideo, Rutube, Yandex Disk и видео внутри лекций могут требовать отдельного безопасного веб-парсинга/авторизации. Нельзя обещать полные транскрипции.
6. Изображения и формулы. OCR русских PDF с изображением проверен; картинки внутри PPT/DOCX, визуальные схемы, таблицы и математические формулы могут потребовать отдельной интерпретации.
7. Глобальный поиск отключён сервером (globalsearchdisabled). Локальный поиск лишь по доступным проиндексированным ресурсам.
8. Требуется включённый домашний Windows ПК. DPAPI-ключи и токен нельзя безопасно копировать на произвольный облачный сервер.
9. Индекс не потоковый: изменения учебных материалов требуют переиндексации. При выдаче результатов перепроверяются актуальные права на исходные модули.

## Безопасность и хранение

Индексы Moodle/материалов/Slides/Drive и токен хранятся в Windows DPAPI на домашнем ПК, не включаются в исходники/архив. Запрещено добавлять в ZIP .moodle_credentials.dpapi, .moodle_materials.dpapi, .moodle_slides.dpapi, .moodle_drive.dpapi, .moodle_hybrid.dpapi, .moodle_browser_profile и любые другие профили или временные секреты.
Исходные документы не отправляются сторонним платным OCR/API.
Поддержке lms@misis.ru ранее отправлены технические вопросы по правам, глобальному поиску и безопасному доступу к урокам.

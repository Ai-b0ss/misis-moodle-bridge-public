# MISIS Moodle — hybrid-v9 (25.10.2026)

## Подтверждённые результаты

1. Google Slides: 32/39 опубликованных презентаций целиком, 691 извлечённый слайд. Ранее v8: 29/39 и 642 слайда; на старте v9: 29/39. Переход к конкретному слайду числом и Enter официально поддерживается режимом презентации Google Slides. Добавлен адресный обход пропущенных номеров. Все 32 публикации, открывающиеся в отдельном браузере, прочитаны, но это **не** означает, что весь графический контент извлечён в текст. Оставшиеся 7 публикаций не открылись; шесть ранее возвращали HTTP 410 Gone.
2. Исправлено сохранение частичных Slides: при исключении просмотрщика старые данные не затираются. Загрузчик пытается восстановить локально частичные результаты при следующем запуске и отдельно сохраняет тип ошибки. Это подтверждено автоматическими тестами и реальным восстановлением ранее сбойной презентации до 46/46 страниц.
3. Видео Яндекс Диска: из 4 обнаруженных записей три уже полностью транскрибированы локально: файлы 23,13, 37,32 и 89,71 МиБ. Суммарно 10,35 минуты русского аудио, 120 фрагментов Whisper с временными метками, сохраняются только в защищённом Windows DPAPI-индексе .moodle_videos.dpapi. Исходные видео/PCM не записывались на диск и не передавались внешним сервисам распознавания. Автоматические транскрипции содержат возможные ошибки.
4. Для 89,71 МиБ создан специализированный bounded downloader с верхним пределом 112 МиБ, HTTPS и списком доверенных CDN Яндекса, проверкой размера по публичному API. Прежний лимит PDF/Office 48 МиБ **не** изменён.
5. Четвёртая видеозапись, около 3,8 ГиБ, не загружалась. Попытка небольшого HTTP Range-запроса вернула от Яндекс CDN HTTP 500. Если доступ восстановится, нужно использовать потоковое или ограниченное по объёму чтение, не переносить весь файл.
6. VK Видео: через публично видимые метаданные обнаружены русские субтитры (VTT) к ролику около 26 минут; два варианта файла размещаются на домене *.okcdn.ru. Попытка прочитать VTT через системный локальный прокси окончилась URLError, поскольку этот прокси недоступен. В публичный CDN **не** выполнялся прямой обход прокси. Поэтому ВК-субтитры пока НЕ проиндексированы. Аналогичная ссылка Rutube не обнаружила субтитров.

## Интеграция

Главный CLI: C:\Users\user\Documents\MISIS-Moodle-Bridge\moodle_client.py
Объединённый поиск: hybrid-search --query "тема" --limit 20.
Slides: slides-index --limit 3 --slide-cap 160; slides-status; slides-search.
Локальные видео: videos-index --limit 1 --clip-minutes 25 --budget-mb 110; videos-status; videos-search.
Полнота поиска ограничена доступными пользователю исходными Moodle-модулями: права и наличие внешних ссылок проверяются заново.

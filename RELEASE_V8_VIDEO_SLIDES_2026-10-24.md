# MISIS Moodle — версия hybrid-v8, 24.10.2026

## Новые функциональные возможности

### 1. Транскрибация видео локально
- Добавлен moodle_videos.py. Он читает только видео из опубликованных ссылок Яндекс Диска, которые ещё присутствуют на доступной студенту странице Moodle.
- Из четырёх видео два небольших (23,13 и 37,32 МБ) успешно загружены в память, звуковые дорожки декодированы через локальный FFmpeg, а русская речь транскрибирована локально моделью Whisper base. Видео и необработанный звук НЕ записываются на диск, не уходят в сторонний API.
- Получены 2/2 полные транскрипции, 6,8 минуты аудио, 61 фрагмент с временными метками, около 2800 символов распознанного текста. Распознавание автоматически и может ошибаться на именах, формулах и терминах.
- Два больших видео (приблизительно 90 МБ и 3,8 ГБ) оставлены как метаданные, без скачивания. Лимит скачиваемого файла 48 МБ, декодирование аудио не более 25 минут за источник, бюджет по умолчанию 100 МБ.
- Команды: videos-index --limit 2 --clip-minutes 25 --budget-mb 100; videos-status; videos-search --query "термин". Единый hybrid-search теперь также ищет по фрагментам транскрипции, возвращает время и ссылку.

### 2. Доработка Google Slides
- moodle_slides.py теперь использует последовательное перелистывание и, при зависании стрелки, альтернативные клавиши и переход End в конец с чтением назад. Частичные находки объединяются по номеру слайда в DPAPI-кеше, не теряя ранее извлечённый текст.
- Полностью прочитано 29/39 презентаций (ранее 25/39); прочитано 642 слайда (ранее 584). Остаются 3 частичные презентации и 7 недоступных; ранее 6 из 7 дали HTTP 410 Gone.

### 3. Уточнение прав на внешние материалы
- Новый moodle_embed_visibility.py реальными read-only API-вызовами проверяет наличие Google Slides и Drive ссылок в актуальном тексте доступных Moodle Page и Lesson. Если преподаватель удалит ссылку, ранее проиндексированный текст не будет показан в поиске.
- Проверено на текущих курсах: 47 из 47 ранее обнаруженных Google ссылок присутствуют и разрешены.
- Аналогичная проверка у Яндекс Диска была реализована в v6.

### 4. Восстановление API при неработающем локальном прокси
- Обнаружено: системная настройка прокси Windows — localhost:7890; во время проверки порт не принимал подключения. Прямая TCP+TLS-связь с Moodle (внутренний IP, проверяемый сертификат HTTPS) работала.
- Изменён исключительно moodle_client.py: при недоступности локального прокси он может повторить запрос прямо к newlms.misis.ru только если DNS Moodle разрешается исключительно во внутренние нелупбэк-адреса; если локальный прокси доступен, прокси сторонний или IP публичный, резервный прямой маршрут не используется.
- Системный прокси, VPN и маршруты для остальных сайтов не изменены. Защищённый файл API-токена по-прежнему хранится локально через Windows DPAPI.
- Прямая проверка после изменения: 7 курсов и 77 Assign API заданий.
- Исходная версия moodle_client.py до изменения сохранена в backups/v8-before-private-routing.

## Итоговые проверки

- 89/89 локальных тестов успешно.
- Сквозной hybrid-search возвращает результаты из всех поддерживаемых источников: Moodle, Moodle вложения, Slides, Google Drive, H5P, Яндекс Диск и видеотранскрипции. В контрольном запросе найден видеофрагмент; ошибок по источникам нет. Время контрольного поиска — около 26 секунд. Это можно оптимизировать в будущем.
- Кеши и авторизация хранятся локально в Windows DPAPI. В архив исходников они НЕ включены.

## Что осталось

- 13 Assign скрыты серверной настройкой uservisible=false.
- 79 страниц Lesson требуют начала активной попытки. Без прямого поручения студента никакие попытки не запускаются.
- Дополнительный браузер Moodle остаётся неавторизованным; для него необходим однократный вход в изолированный Chrome самим пользователем.
- Из 39 Google Slides: 29 полностью, 3 частично, 7 недоступны. Встроенная графика и формулы не обязательно представлены текстом.
- Видео 90 МБ и 3,8 ГБ пока проиндексированы только как метаданные, внешние Rutube/VKvideo ещё требуют адресной проверки.
- Серверный globalsearchdisabled остаётся отключён, используется локальный поиск. Сам пользовательский ПК должен быть включён и подключён к сети.
- Транскрипция Whisper не заменяет проверку сложных формул и имен преподавателем или визуально.
